# 🎬 영화 알리미 (메가박스)

컴퓨터를 꺼놔도 GitHub 서버가 **5분마다** 메가박스를 확인해서 텔레그램으로 알려줘요.
영화·회차·자리는 텔레그램 채팅방의 버튼으로 여는 **선택 화면**에서 눌러서 골라요. 파일을 고칠 필요가 없어요.

- 💺 **자리 감시**: 고른 회차에 조건에 맞는 자리가 생기면 알림 (몇 열 몇 번인지까지)
  - 아무 자리 / 좋은 자리(가운데 블록의 중간~뒤쪽 줄) / 배치도에서 직접 고른 좌석
  - 인원 수, 붙어 있는 자리만 받을지도 정할 수 있음
  - 장애인석만 남은 경우는 "자리 생김"으로 치지 않음
- 🎟️ **예매 오픈**: 관심 영화가 대구 지점에서 새 날짜 예매를 열면 알림
- 🖼️ **아트그라피**, 🎁 관심 영화의 **특전 이벤트**가 새로 올라오면 알림
- ⚠️ 사이트가 바뀌어서 15분 넘게 확인이 안 되면 고장 알림

---

## 설치 (20분 정도)

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름 입력 (예: `경훈 영화 알리미`) → 봇 아이디 입력 (영어, `bot`으로 끝나야 함. 예: `kh_movie_alarm_bot`)
3. BotFather가 주는 **토큰**(`123456789:AAH...` 같은 긴 글자)을 복사해 두기. 비밀번호랑 같으니까 남한테 보여주지 마
4. 방금 만든 봇을 열고 **[시작]** 버튼 누르기 (안 누르면 봇이 메시지를 못 보냄)

### 2. GitHub 저장소 만들고 파일 올리기
1. GitHub 오른쪽 위 **+ → New repository**
2. 이름: `movie-alarm`, **Public** 선택 → **Create repository**
   - Public이어야 GitHub Actions를 무료로 계속 쓸 수 있어 (5분마다 돌리면 비공개 무료 한도를 넘음)
   - 토큰은 3단계에서 Secrets에 넣기 때문에 공개되지 않아. 남이 볼 수 있는 건 고른 영화·회차 정도
3. 파일 올리기는 둘 중 편한 쪽으로:

**컴퓨터로 할 때**
- 만들어진 화면에서 **uploading an existing file** 클릭
- 압축 푼 `movie-alarm` 폴더 **안의 내용물 전부**를 끌어다 놓기 (`.github` 폴더 꼭 포함) → **Commit changes**

**폰으로 할 때** (폴더째로는 못 올리니까 zip 그대로 올림)
- **uploading an existing file** → `movie-alarm.zip` 파일 하나를 그대로 선택 → **Commit changes**
- 저장소 화면에서 **Add file → Create new file**
  - 파일 이름 칸에 `.github/workflows/movie-alarm.yml` 을 그대로 입력 (슬래시를 치면 폴더가 만들어짐)
  - 내용에는 같이 받은 `movie-alarm.yml` 파일의 내용을 전부 복사해서 붙여넣기 → **Commit changes**
- 첫 실행 때 알리미가 zip을 알아서 풀어서 저장소에 넣어 줘 (Actions 탭 → 영화 알리미 → **Run workflow** 를 한 번 눌러도 됨)

4. 저장소에 `.github/workflows/movie-alarm.yml` 이 보이면 성공
   - 이때부터 5분마다 자동 실행되는데, 4단계까지 끝내기 전에는 "등록 전이라 건너뜀"만 찍히는 게 정상이야

### 3. 텔레그램 토큰 등록
저장소 **Settings → Secrets and variables → Actions → New repository secret**
- Name: `TELEGRAM_BOT_TOKEN`
- Secret: 1-3에서 복사한 토큰 → **Add secret**

### 4. 채팅 ID 알아내기
1. 저장소 **Actions** 탭 → 왼쪽 **영화 알리미** → 오른쪽 **Run workflow** → mode: **test** → **Run workflow**
2. 1분쯤 뒤 생긴 실행 기록 클릭 → **check** → **확인** 단계를 펼치면 이런 줄이 있어:
   `===> TELEGRAM_CHAT_ID 후보: 123456789 (경훈)`
3. 그 숫자를 3번과 같은 방법으로 등록 → Name: `TELEGRAM_CHAT_ID`
4. 다시 mode: **test**로 실행 → 텔레그램에 **✅ 영화 알리미 연결 성공**이 오면 끝

### 5. 선택 화면 켜기 (GitHub Pages)
1. 저장소 **Settings → Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `main`, 폴더는 `/docs` 선택 → **Save**
4. 1~2분 뒤부터 `https://내아이디.github.io/movie-alarm/` 이 열려. 알리미가 이걸 확인하면 텔레그램으로 **🎬 선택 화면 준비 완료** 메시지와 함께 채팅창 아래에 버튼을 보내 줘

### 6. 첫 실행 확인 (중요)
1. **Run workflow → mode: debug** 로 한 번 실행
2. 로그에 아래처럼 0이 아닌 숫자가 나오면 정상:
   - `이벤트 N개`
   - `예매 목록 영화 N편, 지점 N곳, 감시 지점 N곳`
   - `[시간표] 지점 N곳, 회차 N개`
   - `좌석 배치도 ...: 좌석 N개 ... 고를 수 있음 N / 사이트 숫자 N` (두 숫자가 같아야 함)
3. 0이거나 빨간 X면 그 로그를 복사해서 Claude한테 보여줘. 메가박스 실제 사이트로는 미리 돌려 보지 못해서, 첫 실행에서 고칠 게 나올 수 있어
4. 정상이면 그냥 두면 돼. 5~10분 안에 **✅ 영화 알리미 시작** 요약이 와

## 쓰는 법

### 자리 감시 걸기
1. 텔레그램 봇 채팅방 아래의 **🎬 영화·자리 고르기** 버튼을 눌러 (안 보이면 입력창 옆 네모 4개 아이콘)
2. 선택 화면에서 **영화관 → 날짜 → 영화 → 회차** 순서로 눌러
   - 회차는 여러 개 골라도 되고, 다른 날짜·영화의 회차를 같이 골라도 돼
   - `매진`, `사실상 매진(장애인석만 남음)` 회차를 골라 두면 취소표가 나올 때 알려 줘
3. **자리 조건**을 정해
   - **인원**: 2명 이상이면 "붙어 있는 자리만"을 켤 수 있어
   - **아무 자리**: 어디든 일반석이 인원수만큼 나면 알림
   - **좋은 자리**: 가운데 절반 폭, 앞에서 45~85% 위치의 줄. 배치도에 노랗게 표시돼
   - **직접 고르기**: 배치도에서 좌석을 눌러서 지정. 좌석이 작으면 **크게 보기**
4. 아래 **보내기** 를 누르면 화면이 닫히고, 5분 안에 **✅ 요청 처리 완료** 답장이 와
5. 조건에 맞는 자리가 생기면 **💺 자리 생김** 알림이 와. [지금 예매하기]를 누르면 메가박스로 가

### 감시 보기·지우기
- 채팅창의 **📋 감시 목록** 버튼 → 목록과 함께 [🗑 1번] 같은 삭제 버튼이 와
- 선택 화면의 **내 감시** 탭에서도 지울 수 있어 (삭제 누르고 보내기)
- 상영이 시작되면 감시는 자동으로 끝나

### 관심 영화 (예매 오픈·특전 알림)
- 선택 화면의 **관심 영화** 탭에서 제목을 적거나, 상영 중인 영화를 눌러서 추가
- 아직 예매가 안 열린 영화도 제목 일부만 적어 두면 열릴 때 알려 줘

### 시간표가 옛날 거 같을 때
- 채팅창의 **🔄 시간표 새로고침** 버튼 → 1~2분 뒤 선택 화면을 다시 열기 (평소엔 20분마다 자동 갱신)

---

## 알아둘 점
- 보내기를 누른 뒤 답장까지 **최대 5~10분** 걸릴 수 있어. GitHub가 5분마다 깨어나서 확인하기 때문이야
- 감시가 걸려 있는 동안에는 한 번 깨어날 때 **약 70초 간격으로 3번** 확인해. 그래도 인기 회차의 취소표는 몇 분 안에 나가기도 하니까, 알림이 오면 바로 들어가 봐
- 같은 감시는 15분 안에 다시 알리지 않아 (결제 중인 좌석이 잠깐 풀렸다 잡혔다 하는 경우 때문). 15분 뒤에도 자리가 남아 있으면 다시 알려 줘
- 감시는 20개까지
- 저장소에 `data` 라는 브랜치가 자동으로 생겨. 알리미가 기억할 내용(감시 목록, 시간표)을 넣어 두는 곳이니까 지우지 마

## 문제 해결
| 증상 | 해결 |
|---|---|
| 알림이 하나도 안 옴 | Actions 탭에 실행 기록이 있는지, 빨간 X인지 확인 |
| 채팅창에 🎬 버튼이 없음 | 5단계(Pages)를 했는지 확인. 했다면 봇에게 아무 글자나 보내면 5분 안에 메뉴를 다시 보내 줘 |
| 선택 화면에 "아직 받아 온 시간표가 없어요" | 알리미가 한 번 돌 때까지 5~10분 기다리기. 계속 그러면 debug 로그 확인 |
| 보내기를 눌렀는데 코드 복사 창이 뜸 | 선택 화면을 채팅창의 🎬 버튼이 아닌 다른 방법으로 연 경우야. 코드를 복사해서 봇 채팅방에 붙여넣어 보내면 똑같이 처리돼 |
| `Permission ... denied` / push 실패 | Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save |
| ⚠️ 영화 알리미 오류 알림이 옴 | mode: **debug**로 실행 → 로그를 Claude한테 |
| 지점을 못 찾았다는 알림 | 알림에 나온 "비슷한 지점" 이름으로 `config.yaml` 수정 |
| 잠깐 끄고 싶음 | Actions → 영화 알리미 → ⋯ → Disable workflow |

## 파일 구성
```
docs/index.html                 선택 화면 (텔레그램 버튼으로 열림)
config.yaml                     기본 설정: 지역(대구), 이벤트 단어 등. 평소엔 안 건드려도 됨
alarm/main.py                   실행 순서, 오류 알림
alarm/bot.py                    텔레그램에서 온 요청 처리 (선택 화면이 보낸 내용, 버튼)
alarm/watch.py                  자리 감시
alarm/seats.py                  좌석 배치도 해석, 좋은 자리·붙은 자리 판정
alarm/catalog.py                선택 화면에 보여줄 시간표·배치도 만들기
alarm/megabox.py                메가박스에서 이벤트·지점·회차·좌석 읽기, 예매 오픈 확인
alarm/notify.py                 텔레그램 전송
alarm/state.py, scripts/data.sh 기억할 내용 저장 (data 브랜치)
.github/workflows/movie-alarm.yml  5분마다 실행 설정
```

선택 화면의 숫자 글꼴은 Doto(SIL Open Font License 1.1)에서 숫자만 잘라 넣었어.
